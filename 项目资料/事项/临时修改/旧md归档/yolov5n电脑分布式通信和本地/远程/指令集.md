# 远程视觉（电脑识别）：指令集

小车只拍摄、编码、发布话题；**电脑**用 YOLOv5n 识别，结果传回小车。小车上不用 conda、CANN、NPU、torch。
详细原理、参数、排错见同目录 `运行指令_详细版.md`、`README_远程视觉.md`。

## 0. 前提

- 小车仓库已经包含这些文件（提交 `641ae59`，小车 `main` 和电脑一致），**不需要再 `scp`**。
- 电脑端用 `D:\light_ai\venv`（装了 onnxruntime、torch、opencv），模型为 `D:\VSCode\ros2技术集\智能车总文件\视觉模型\模型\yolov5n_best.onnx`。
- 电脑连着小车的 WiFi，IP 在 `192.168.5.x`，没有开 VPN。
- 摄像头同一时间只能被一套程序占用：先停掉本地识别（`start_vision.sh`），详见 `本地\指令集.md`。

## 4. 接入运动控制（要联动 `pure_track_test` 时才用）

小车：

```bash
cd /home/racecar/src/my_racecar/camera_capture && bash start_remote_vision.sh --enable-control
```

- 加了 `--enable-control`：桥会订阅 `/traffic_light_req`，**收到 1 期间**才发布 `/traffic_light`：识别为 `green` 发 1，其他状态（含 `stale`）发 0；收到 0 就停止发布。没有请求时不发任何 `/traffic_light`。
- 不加该参数：只发 `/traffic_state`、`/traffic_light_box`，完全不影响运动。
- 运动代码要用到：`light_mode: 1`、`traffic_light_index`（现在 258，需现场标定）、`traffic_light_time`（10 秒，超时放行）。
- 第一次接入建议架空轮子；改了 C++ 要自己 `colcon build` 才会生效。
- 只验证过语法和命令行参数，这条 ROS 路径还没在车上跑过。

## 5. 常用参数

小车端（接在 `bash start_remote_vision.sh` 后面）：

```bash
bash start_remote_vision.sh --fps 10 --quality 70
bash start_remote_vision.sh --stale-sec 0.8
```

环境变量 `BIND` 可设监听地址：

```bash
BIND=192.168.5.100 bash start_remote_vision.sh
```

电脑端：

```powershell
D:\light_ai\venv\Scripts\python.exe pc_vision_client.py --car 192.168.5.100 --conf-box 0.4 --conf-lamp 0.4 --confirm 3
```

## 6. 验证清单

| 项目 | 做法 | 通过标准 |
|---|---|---|
| 端口能通 | 电脑 `Test-NetConnection 192.168.5.100 -Port 9000` | `TcpTestSucceeded : True` |
| 连通 | 小车日志出现 `电脑已连接` | 往返延迟 p50 约 70 到 110 ms（上次实测） |
| 话题 | 小车 `ros2 topic hz /traffic_state` | 约 20 Hz |
| 断线 | 关掉电脑端程序 | 小车 0.5 秒内 `/traffic_state` 变 `stale`，重开后自动恢复 |
| 红判绿 | 对红灯看一段时间 | 不出现 `green` |

上次实测还出现过 WiFi 抖动：往返 p95 冲到约 3.4 秒，状态在 `stale` 和正常之间来回跳。原因没有查清（可能是 WiFi），可持续 `ping -t 192.168.5.100` 排查；接控制前可以考虑把 `--stale-sec` 放宽到 0.8 或 1.0。

## 7. 停止

- 电脑端：窗口里按 `q`，或终端 `Ctrl+C`。
- 小车端：`Ctrl+C`。
- 确认摄像头已释放：`fuser -v /dev/video0`（没有输出即可）。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| `can't open file '...\pc_vision_client.py'` | 要先进 `camera_capture` 目录，文件不在仓库根目录 |
| `连不上 192.168.5.100:9000` | 小车端没启动或已报错退出；电脑不在 `192.168.5.x`；开了 VPN |
| 小车启动报摄像头被占用 | 先关 `start_vision.sh`、`record_video.py` 等，再 `fuser -v /dev/video0` 确认 |
| 小车提示 `light_infer.py 已经在运行` | 本地识别没关，先停掉它 |
| PowerShell 不让运行 `.ps1` | 用 `powershell -ExecutionPolicy Bypass -File ...`，或直接运行 `pc_vision_client.py` |
| 状态频繁 `stale` | 看延迟 p95 是否过大；检查 WiFi；或加大 `--stale-sec` |
| 电脑和小车不同步（git） | 见 `..\..\git和小车修改冲突解决方法\指令集.md` |
