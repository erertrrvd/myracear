# yolov5n11n.om训练过程

**先看 `训练与部署全过程.md`**：采集 → 标注 → 训练（YOLOv5n、YOLO11n）→ 导出 ONNX → 转 `.om` → 验证 → 车上运行的全部过程、指令、结果、问题与解答。

| 目录 / 文件 | 内容 |

| `训练与部署全过程.md` | 主文档（含完整复现指令清单） |

| `03_训练/` | 训练配置模板、YOLOv5n 和 YOLO11n 的结果曲线与 `results.csv` |
| `04_转om/` | 转换工程、ONNX 和 `.om` 检查脚本、Linux 电脑上转换的说明 |
| `05_验证/` | 识别与判断逻辑、验证集对比脚本、电脑摄像头试验脚本 |
