scp 到电脑的命令在小车终端里运行了记录
现象

取回小车视觉改动时，scp ... "$env:USERPROFILE\..." 在小车终端里执行，补丁没拷到电脑。

排查
# 小车：检查有没有留下杂文件
cd /home/racecar/src/my_racecar && git status --short; ls -la /root /home/racecar/src/my_racecar | grep -i userprofile
原因

$env:USERPROFILE 是 PowerShell 的写法，scp 到电脑必须在电脑 PowerShell 里运行。

解决

有杂文件就贴出来确认后再删；补丁还在小车 /tmp/，在电脑 PowerShell 里重新 scp。

回退（破坏性，先备份）

车快时锥桶黑点淡、模糊（2026-10-19，新增实体化障碍层）有结果
现象

高速建图时锥桶在 map.png 里只剩零散一两个黑点，有的缺；墙有断口。

排查

统计已保存地图的像素：只有 0（障碍）、205（未知）、254（空闲）三种值，没有中间灰度。所以“淡”不是颜色浅，是障碍点又少又散。

slam_toolbox 每格按“命中 / 穿过”比例判障碍：车快时锥桶只被扫到一两次，旁边擦过的射线多，被判成空闲或未知。

原因

slam_toolbox 的占据栅格本身的特性，不是参数问题；只调阈值会把走动的人一起留下。

解决

新增 mapping/scripts/obstacle_layer（快捷键 4 开、2 不开），发 /map_solid（只用来看）。第二版做法（第一版的问题见下一张卡片）：

1) 位置只用 SLAM 原图 /map：找“小而孤立”的障碍点团（相邻 1 格内连成一团，大小 <= 0.35 m），换成实心圆；墙和其他障碍保持原样。

2) 孤立：外环（离锥桶边缘 0.15~0.40 m）别的障碍格 <= 10（墙碎片远多于此），且外环里已探明空闲格 >= 60%（房间外、射线边缘的噪点周围大多是未知）。

3) 半径：近处（2.5 m 内）单帧里的短段做圆拟合（最小二乘 + Gauss-Newton）取中位数；单帧只用相对形状，和位姿无关。会移动的物体（人腿）在里程计坐标系里短时跟踪（3 s）后排除。

4) 画图：先清掉锥桶周围 0.25 m 内原来的散点，再画和圆有重叠的格子（8 cm 半径 = 3x3 格）。

人：filtered 模式的原图本来就基本不留走动的人，实体层只把原图已有的点团变实。原图里一个点都没有的锥桶补不出来。

save_mapping 有 /map_solid 时多存 map_solid.* 和 solid.json；run_slam_windows.ps1 加 -NoSolid。

结果

实车 10-19 20:17 那张原图离线加工：画出 77 个锥桶，和原图锥桶排布一致；房间外噪点全部去掉；拟合半径 0.082 m（1581 个单帧样本）。

房间里还有几个零星的圆，原图那里本来就有小黑点（可能是椅子腿等真实小物体）。这些和靠边的点在第三版里处理，见下一张卡片。

实体层第二版：靠边的东西也被画成锥桶；刚开始建图出现特别大的圆（2026-10-19）有结果
现象

赛道锥桶正确，但门口一簇杂点、靠墙的几个点也被画成了圆；建图刚开始时有几个圆明显比锥桶大。

排查

用 20:27 那趟保存的原图离线加工，彩色差异图对比（红 = 新增，蓝 = 清掉）。

到房间外未知、到别的点团的距离：门口杂点 0.22~0.34 m 内就有别的小点；赛道锥桶最近邻居 >= 0.5 m（内圈间距只有 0.5~0.6 m）。

外环 0.25~0.49 m 时内圈锥桶被邻居误拒；只看“任何未知”时锥桶背后的阴影把旁边锥桶也判成边缘；只看长墙时门口的断墙不算。

原因

边缘的定义太粗；半径样本里混进了墙角、平墙段拟合出的大圆。

解决

边缘 = 和地图边界连通的未知（房间外；被空地包住的阴影不算）+ 长度 > 3 m 的墙 + 贴着房间外边 1 m 内、>= 0.4 m 的物体（断墙、门框）。离边缘 edge_margin（1.0 m）内的点团不加工。

相距 1 个空格内的碎块先合成一团（淡锥桶常被拆成两三块）；外环改为锥桶边缘外 0.08~0.25 m，只数别的团的格子，> 2 格不加工。

半径样本只收“凸向雷达”（圆心在点后面）且覆盖 >= 60° 的圆弧。

结果

20:27 原图：赛道锥桶基本都画了；底边、顶边靠墙的和门口大部分不再加工；门口还剩 2 个圆（原图里也是圆点，可能真是锥桶）。顶边 1 个赛道锥桶离墙凸起不到 1 m，没被加工。

edge_margin 调到 1.2 / 1.4 会误伤更多顶边锥桶，所以保持 1.0。模拟走廊只有 4 m 宽，锥桶离墙 0.8 m，默认参数下一个都不加工（edge_margin 0.5 时 12/12）。

实车 10-19 20:54、21:09 两趟带实体层建图：实体层记录 68 / 70 个锥桶，半径 0.0815 / 0.0818 m（各约 350 个单帧样本）。两趟都没按 3 保存，用 autosave 原图离线复查：赛道锥桶都是大小一致的圆，墙和房间外按原图，没有假黑块，也没有过大的圆；个别离内部短墙近或点团太碎的锥桶没加工。

还没验证：按 3 保存时 map_solid.png / solid.json 是否正常写出（autosave 只存原图）。离线复查命令见八、调试命令 8.5.1。

实体层第一版：实车出现大片不存在的黑块和斜线（2026-10-19）记录
现象

第一版实体层在实车上锥桶变清晰了，但空地上出现很多黑色条带、大黑块，整张图像被斜着叠了好几层。

排查

同一时刻自动保存的 SLAM 原图是干净的（锥桶、墙都对），黑块全是实体层画的。

.run1-live.jsonl 最后一行 corr（SLAM 对里程计的修正）偏航 21.75°：里程计朝向漂得很厉害，SLAM 一直在往回拉。

原因
